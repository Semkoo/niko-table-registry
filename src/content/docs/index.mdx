## Install

**Nobody's table, everyone's solution.**

This is not an npm package. The CLI copies the `DataTable` source into your project, so you own it. It is built with TanStack Table and shadcn/ui.

Add the registry once under `registries` in `components.json`, then install:

```json title="components.json"
{
  "registries": {
    "@niko-table": "https://niko-table.com/r/{style}/{name}.json"
  }
}
```

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table" />

Works with Radix UI, Base UI and React Aria. Like shadcn/ui, the CLI installs the version that matches your project.

See [Installation](/getting-started/installation/) to add it to an existing `components.json`.

## Key Features

- **Type-safe** - Full TypeScript support
- **Accessible** - Built on shadcn/ui primitives (Radix or Base UI). Filters and menus have ARIA labels and keyboard shortcuts. Code is linted with jsx-a11y.
- **Responsive** - Full-width scroll container (`overflow-auto`) and touch-friendly controls. Stack toolbars on small screens as needed.
- **Customizable** - You own the source code
- **Composable** - Mix and match `DataTable*` components. Install only the pieces you need. TanStack Table v9 works the same way: register only the features you use in `lib/data-table-features.ts`.
- **Built from shadcn/ui** - Every component reuses the shadcn/ui components already in your project (Button, Popover, Command, Dropdown Menu and more), so tables match your theme with no extra styling.
- **Performance** - Virtual scrolling keeps hundreds of thousands of client-side rows smooth. The [Niko Grid stress test](/data-grid/introduction/) loads 500,000 rows in the browser.
- **State Management** - `useDataTable()` reads state from context. State can be controlled, and can sync to the URL with nuqs.
