## November 2026

### New

- **Blocks.** Full screens you install with one command and then own. [Browse blocks](/blocks/)
  - Customers, Orders, Support Tickets
  - Team Members, Invoices, API Request Logs
  - Inventory Grid, Sprint Backlog, Shipments, Transactions Ledger
  - The Blocks page shows a live preview of each, grouped by category.
- **Example galleries.** Every example as a card with a live preview.
  - [Table Examples](/examples/)
  - [Grid Examples](/data-grid/examples/)
- **GitHub stars.** The header shows the star count.
- **React Aria (new, experimental).** Niko Table now installs on shadcn React Aria projects, like Radix UI and Base UI.
  - The registry line changed to `https://niko-table.com/r/{style}/{name}.json`. The old line still works on Radix and Base UI. [Installation](/getting-started/installation/#radix-ui-base-ui-and-react-aria)
  - `shadcn search`, `list` and `view` work on React Aria too.
  - Known gaps:
    - Popovers, menus and the right-click menu are always modal: the page does not scroll while one is open.
    - Arrow keys do not move between menu items and a search box or other controls inside the same menu. Tab and the mouse do.
    - Right-click menus do not open with a long press on touch, and after one closes, focus goes to the page, not the row.
    - The command list (search in filters and menus) uses cmdk and keeps the Radix look.
    - A picked date cannot be cleared by clicking it again, and a date range only reports once both ends are picked.
    - Help icons with a tooltip are an extra Tab stop, and tooltips open on hover only after a first click on the page.
    - shadcn's own React Aria `components/ui/label.tsx` imports `React` without using it, which fails strict TypeScript (`noUnusedLocals`). Delete that import line. It is a shadcn issue, not Niko Table.

### Changed

- **Installs add a primitives folder.**
  - New files in `components/niko-table/primitives/` pass through to your shadcn components.
  - The table works the same as before.
  - They let the same table install on React Aria.
- **Data Grid is now called Niko Grid.**
  - Only the name changed.
  - Install names (`data-table-grid`) and URLs (`/data-grid/`) are the same.
- **`onReorder` tells you which row moved.** It gets an optional second argument, `{ activeId, overId }`. Existing code keeps working.
- **Easier navigation.**
  - Breadcrumbs show where a page sits, and every step is a link.
  - Sidebar examples are grouped and fold away.
  - The Preview / Code switch is smaller.
- **"Open in v0" is removed** from example previews.

### Fixed

- **Undo after typing in a grid cell works in development.** With React StrictMode on, the first typed character was saved as its own undo step.
- **Right-click menus work on draggable rows.** They never opened before, in regular and virtualized tables.
- **Docs lists show bullets again.** Sub-points are indented.
- **Some installs were missing a component.**
  - Data Table, Data Table Core and the column slider filter now install everything they use.
- **New Vite projects now build.** Installing into a fresh `shadcn init -t vite` app used to fail the type check.

## July 2026

### New

- **Niko Grid.** An editable spreadsheet grid on top of Niko Table. [Introduction](/data-grid/introduction/)
  - Track and save edits with `useGridChanges`. [Persistence](/examples/persistence-grid/)
  - Show validation errors on the cell. [Validation](/examples/validation-grid/)
  - Edit against a server, loading rows as you scroll. [Server-Side Grid](/examples/server-side-grid/)
- **Base UI support.** Everything installs on both shadcn generations: Radix and Base UI.
- **Row grouping.** Group by any column from its menu, with totals per group. [Grouping Table](/examples/grouping-table/)
- **Column resize.** Add `<DataTableColumnResize />`. [Column Resize Table](/examples/column-resize-table/)
  - Drag, use the keyboard, or double-click to fit the content.
  - Columns fill the table width by default.
  - Optional: spread spare width evenly with `<DataTableColumnAutoFit />`.
  - Optional: remember widths with `useColumnSizingPersistence`.
- **Smaller installs.**
  - `data-table-core` holds the shared base, so single controls no longer pull the whole table.
  - `data-table-ui` holds the table primitive, so your customized `table.tsx` is not overwritten.
- **Typed column helper.** `createDataTableColumnHelper` gives typed `getValue()` in cells. [Lib](/niko-table/overview/lib/)
- **Drizzle ORM guides.** Server-side tables with Postgres.
  - [Drizzle ORM](/examples/drizzle-orm/)
  - [Drizzle ORM + Nuqs](/examples/drizzle-orm-nuqs/) (table state in the URL)
- **`normalizeFiltersFromUrl`.** Restore advanced filters from a URL.
- **New registry items** for virtualized row and column drag-and-drop.

### Changed

- **TanStack Table v9. This is a breaking change.**
  - Code you already copied keeps working on v8 until you upgrade.
  - `VisibilityState` is now `ColumnVisibilityState`.
  - `table.getState()` is now `table.state`.
  - Column pinning uses `start` / `end` instead of `left` / `right`.
  - Saved v8 pinning is ignored, so pinned columns reset once after you upgrade.
  - Filter option counts can shift on tables you build yourself.
  - See TanStack's [migration guide](https://tanstack.com/table/latest/docs/framework/react/guide/migrating).
- **Server-side examples reworked.** One query format, with every filter working on the server. [Server-Side Table](/examples/server-side-table/)
- **Sorting is off by default.** Turn it on in config, or add a sort control.
- **Resizing applies when you release the drag.** A preview line shows the new width while you drag.
- **Drag-and-drop imports moved.** Use `data-table-row-dnd-structure` and `data-table-column-dnd-structure`.
- **Docs.** The Installation page and the [Skills](/getting-started/skills/) page cover Niko Grid and both shadcn generations.

### Removed

- `data-table-dnd-structure.tsx` and `data-table-virtualized-dnd-structure.tsx`. Use the row and column files above.

### Fixed

- **Fresh installs were broken.** Two files were missing from the registry. They now ship with `data-table`.
- **Column resize.**
  - Cell text no longer spills into the next column.
  - The grip stays hidden until you hover or focus it.
  - Pinning plus resizing no longer clips the first column.
  - Resize now works with row and column drag-and-drop.
- **Niko Grid.**
  - Undo, redo, filter and hide no longer leave a ghost focus.
  - Scroll into view works with right-pinned columns.
  - Selection and highlights follow the sorted and filtered order.
- **Dynamic columns.** Adding or removing a column no longer leaves stale cells.
- **Drag-and-drop.** No more hydration warnings on server-rendered pages.
- **Server-side examples.** Single-date filters match on the server.

## May 2026

### New

- **`getRowMemoKey`.** Re-render only the row whose outside state changed, for example a row being edited. [Inline Edit Table](/examples/inline-edit-table/)
- **`DataTableVirtualizedFlexHeader`.** The header to pair with the virtualized row drag-and-drop body.

### Changed

- **Options with a count of 0 are hidden** in every filter. To keep one, pass `count: undefined`.
- **Sorting or filtering no longer jumps to page 1.** To get that back, set `autoResetPageIndex: true`.
- **`onRowSelection` no longer fires on first load.** It fires only when the user changes the selection.

### Fixed

- **Filter counts went stale** after other filters changed. They now update.
- **Range filter.** The min and max refresh when the data changes.
- **Slider filter.** The clear button no longer re-opens the popover.
- **CSV export.** Objects export as JSON instead of `[object Object]`.
- **Row selection.** Rows with sequential IDs are matched correctly.
- **Virtualized tables.**
  - Expanded rows are measured correctly.
  - Selected rows are styled in the row drag-and-drop body.
- **Date filter.** The unfinished "relative" option is hidden.
- **No more "state update on unmounted component" warnings.**

### Faster

- One click listener per table instead of one per row.
- Scroll callbacks fire once when you reach the top or bottom.
- Fewer re-renders in headers, menus and filters.

## April 2026

### New

- **Loading-more rows** for infinite scroll: `DataTableLoadingMore` and `DataTableVirtualizedLoadingMore`.
- **`onNearEnd`.** Load the next page before the user reaches the bottom. More reliable than `onScrolledBottom`.
- **New examples.**
  - [Infinite Scroll Table](/examples/infinite-scroll-table/)
  - [Infinite Scroll Virtualized Table](/examples/infinite-scroll-virtualized-table/)

### Changed

- **Virtualized tables use a native `<table>` layout.** Column widths come from the content, then lock.
- **Multi-select faceted filters show every option**, not only the ones in the filtered rows.
- **The `preserve` merge strategy** leaves your options untouched. Only `augment` adds counts.

### Fixed

- **Virtualized tables.** Columns no longer squeeze together on wide data.
- **Scroll callbacks.** `onScrolledTop` and `onScrolledBottom` work without an `onScroll` handler.
- **Faceted filter.** `dynamicCounts` is respected everywhere.

### Behind the scenes

- Tests added with Vitest.
- GitHub Actions run tests, lint and build on every pull request.

## March 2026

### Fixed

- **Pagination.**
  - The page input commits on Enter or blur.
  - Changing the page size keeps your place.
- **Sticky header.** Pinned cells no longer overlap it.

### Faster

- Row clicks are handled once per table instead of once per row.
- Handlers in `DataTableRoot`, pagination and the aside are stable between renders.

## February 2026: First release

Niko Table launched: composable, shadcn-compatible data tables built on TanStack Table.

### Components

- **Tables:** `DataTable`, `DataTableVirtualized`
- **Pagination:** `DataTablePagination`
- **Filters:** search, faceted, filter menu, inline, slider, date
- **Columns:** sort, hide, pin
- **Extras:** export button, aside panel, selection bar

### Features

- **Rows:** selection, expansion, tree data, drag-and-drop
- **Columns:** drag-and-drop reordering
- **Large data:** virtualization for 10,000+ rows
- **URL state:** filters, sorting and pagination in the URL with `nuqs`
- **Server-side:** filtering, sorting and pagination

### Filter system

- 15+ operators, such as contains, equals, greater than and between
- Mix AND and OR in one filter set
