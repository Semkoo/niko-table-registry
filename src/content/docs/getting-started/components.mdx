A cheat sheet of every item in the niko-table registry. Browse by category, or search this page.

- **Every add-on pulls in `data-table-core`.** That is context, structure, types and `lib/data-table-features.ts`. It does not include `DataTableRoot` or `table.tsx`.
- **Own the TanStack instance?** Any control gives you enough to render a body.
- **Want the usual setup?** Add `@niko-table/data-table`. It depends on `data-table-core` and `data-table-ui`.

> First time using `@niko-table`? Set up the registry once. See the [Installation Guide](/getting-started/installation/#configure-the-registry).

## Core

The shared base (`data-table-core`), the optional table primitive (`data-table-ui`) and the full owner (`data-table`).

| Name              | What it does                                                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data-table-ui`   | Optional `components/ui/table.tsx` with `TableComponent` and a keyboard-focusable scroll container (`tabIndex={0}`). Skip it if you already have a compatible table.             |
| `data-table-core` | Context, non-virtualized structure, types, config, and the lib and hooks that bodies and controls need. No `DataTableRoot`, no `table.tsx`.                                      |
| `data-table`      | Full owner on top of core: `DataTableRoot`, `DataTable`, toolbar and column chrome, feature detection, scroll and flash hooks. Pulls in `data-table-ui` for the Table primitive. |

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table" />

If you own the table instance (manual server-driven mode), install controls only. They pull in `data-table-core` and skip Root **and** `table.tsx`, so your customized Shadcn table is safe:

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table-pagination @niko-table/data-table-search-filter @niko-table/data-table-faceted-filter @niko-table/data-table-clear-filter @niko-table/data-table-column-sort" />

Want our table primitive without the full owner?

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table-ui" />

## Toolbar Filters

Filter controls above the table. Each one is independent. Install only what you need.

| Name                        | What it does                                                                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `data-table-search-filter`  | Global search input with debounce.                                                                                                                           |
| `data-table-pagination`     | Page-size picker, page navigation and row count.                                                                                                             |
| `data-table-sort-menu`      | Multi-column sorting, with drag-to-reorder of sort entries.                                                                                                  |
| `data-table-view-menu`      | Menu to show or hide columns. Optional `lockedColumnIds` and `onReset`.                                                                                      |
| `data-table-view-dnd-menu`  | Column visibility menu **with drag-to-reorder**. Use it instead of `data-table-view-menu` to let users reorder columns from the menu. Pulls in `@dnd-kit/*`. |
| `data-table-filter-menu`    | Command-palette-style menu to add and manage column filters.                                                                                                 |
| `data-table-inline-filter`  | Inline toolbar that shows active filters as editable chips.                                                                                                  |
| `data-table-faceted-filter` | Faceted filter (single or multi select) with option counts and search.                                                                                       |
| `data-table-slider-filter`  | Slider filter for a number range.                                                                                                                            |
| `data-table-date-filter`    | Date picker filter for a single date or a date range.                                                                                                        |
| `data-table-clear-filter`   | Button that clears all active filters.                                                                                                                       |

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table-search-filter @niko-table/data-table-pagination @niko-table/data-table-view-menu" />

## Column-Header Controls

Per-column controls in the column header dropdown.

| Name                                   | What it does                                                                                                                            |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `data-table-column-sort`               | Header sort option: asc, desc or clear.                                                                                                 |
| `data-table-column-hide`               | Header option to hide or show the column.                                                                                               |
| `data-table-column-pin`                | Header option to pin the column left or right.                                                                                          |
| `data-table-column-group`              | Header **Group by** and **Stop grouping by**. Groups flat rows into buckets with aggregations (not tree `getSubRows`).                  |
| `data-table-column-resize`             | Column resize handle. Double-click to autosize. Flex fill and header-fit are on by default once resizing is on.                         |
| `data-table-column-auto-fit`           | Opt-in `<DataTableColumnAutoFit />` marker. Splits leftover width evenly across resizable columns (instead of single-column flex fill). |
| `data-table-column-sizing-persistence` | `useColumnSizingPersistence(storageKey)` hook. Saves resized widths to `localStorage`.                                                  |
| `data-table-column-faceted-filter`     | Header faceted filter with multi-select options.                                                                                        |
| `data-table-column-slider-filter`      | Header slider filter for a number range.                                                                                                |
| `data-table-column-date-filter`        | Header date filter with calendar picker.                                                                                                |

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table-column-sort @niko-table/data-table-column-hide @niko-table/data-table-column-pin @niko-table/data-table-column-group @niko-table/data-table-column-resize @niko-table/data-table-column-auto-fit @niko-table/data-table-column-sizing-persistence" />

## Drag and Drop

Reorder rows and columns. Pulls in `@dnd-kit/*`.

| Name                                | What it does                                                                                       |
| ----------------------------------- | -------------------------------------------------------------------------------------------------- |
| `data-table-row-dnd`                | Row drag-and-drop (provider, drag handle, `DataTableDndBody`). Does not ship column DnD.           |
| `data-table-column-dnd`             | Column drag-and-drop (provider, header, `DataTableDndColumnBody`). Does not ship row DnD.          |
| `data-table-virtualized-row-dnd`    | Virtualized row DnD body. Depends on `data-table-virtualized` + `data-table-row-dnd`.              |
| `data-table-virtualized-column-dnd` | Virtualized column DnD header/body. Depends on `data-table-virtualized` + `data-table-column-dnd`. |

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table-row-dnd @niko-table/data-table-column-dnd @niko-table/data-table-virtualized-row-dnd @niko-table/data-table-virtualized-column-dnd" />

> Do not combine Row DnD with sorting or filtering. The data order conflicts. Column DnD is safe with any feature.

| Name                      | What it does                                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `data-table-grid`         | Niko Grid core: keyboard navigation, clipboard, fill and typed cells. Pulls in virtualization and column resize. |
| `data-table-grid-changes` | Optional change tracking (`useGridChanges`) to save creates, updates and deletes.                                |
