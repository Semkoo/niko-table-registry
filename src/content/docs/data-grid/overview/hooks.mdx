### useDataGrid

The headless engine. It holds rows, focus, selection, editing, and undo/redo. It has no domain logic.

<div className="not-content mb-4 flex items-center gap-2">
  <DocsLink href={`${GITHUB_REPO_URL}/blob/main/src/components/niko-table/grid/hooks/use-data-grid.ts`} external>Source Code ↗</DocsLink>
  <DocsLink href="/data-grid/api/">API Reference ↗</DocsLink>
</div>

```tsx showLineNumbers
import { useDataGrid } from "@/components/niko-table/grid/hooks/use-data-grid"

const grid = useDataGrid<TRow extends GridRow>({
  columnIds,         // editable column ids (visual order)
  createEmptyRow,    // (id) => TRow
  initialRows,       // seed data (optional)
  initialRowCount,   // blank seed count when no initialRows (default 5)
  maxRows,           // hard cap (default 200)
  makeId,            // runtime inserts only (default crypto.randomUUID)
})
```

- Blank seeds from `initialRowCount` get fixed ids like `row-0` (safe for SSR).
- Runtime `addRows`, `insertRows`, and `clearAll` use `makeId`.

#### Config

| Name              | Type                   | Default | Description                            |
| ----------------- | ---------------------- | ------- | -------------------------------------- |
| `columnIds`       | `readonly string[]`    | -       | Editable column ids in visual order    |
| `createEmptyRow`  | `(id: string) => TRow` | -       | Factory for blank rows                 |
| `initialRows`     | `TRow[]`               | -       | Seed with exact rows                   |
| `initialRowCount` | `number`               | `5`     | Blank seed count when no `initialRows` |
| `maxRows`         | `number`               | `200`   | Hard cap                               |
| `makeId`          | `() => string`         | UUID    | Runtime inserts only                   |

#### Return values (high level)

| Field                                                                             | Purpose                                                            |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `rows`                                                                            | Pass to `DataTableRoot data`                                       |
| `lastCommit`                                                                      | Last change signal. See [Persistence](/examples/persistence-grid/) |
| `focusedCell` / `editingCell` / `selectionAnchor`                                 | Cursor + range by `{ rowId, columnId }`                            |
| `selectCell` / `deselect` / `extendSelectionTo`                                   | Move, clear, or extend selection (all leave edit mode)             |
| `startEditing` / `stopEditing`                                                    | Open / close the editor                                            |
| `setCell(rowId, colId, next)`                                                     | O(1) commit: one row identity changes                              |
| `updateRows` / `addRows` / `insertRows` / `removeRow` / `removeRows` / `clearAll` | Row mutations (undoable)                                           |
| `undo` / `redo` / `canUndo` / `canRedo`                                           | History                                                            |

`updateRows(fn, { history: false })` updates derived state (like cross-field validation) without adding an undo step. See [Validation](/examples/validation-grid/).

### useGridChanges

Separate install: `@niko-table/data-table-grid-changes`. It reads `grid.lastCommit`.

<div className="not-content mb-4 flex items-center gap-2">
  <DocsLink href={`${GITHUB_REPO_URL}/blob/main/src/components/niko-table/grid/hooks/use-grid-changes.ts`} external>Source Code ↗</DocsLink>
  <DocsLink href="/examples/persistence-grid/">Persistence ↗</DocsLink>
</div>

```tsx showLineNumbers
const changes = useGridChanges(grid, { initialRows })
changes.isDirty
changes.getChangeSet() // { created, updated, deleted }
changes.reconcile({ succeededIds, failedIds })
```

### Internal hooks

Core and feature components use these. You rarely import them in app code.

| Hook                              | Role                                                                     |
| --------------------------------- | ------------------------------------------------------------------------ |
| `useGridKeyboard`                 | Scoped keydown state machine                                             |
| `useGridNavigation`               | Arrow / Tab / Home / End movement                                        |
| `parseTsv` / `serializeSelection` | TSV parse / serialize helpers (plain functions, `use-grid-clipboard.ts`) |
| `useDataGridContext`              | Context (lives in core). Throws outside the provider                     |
