## CellStatus

```ts
type CellStatus = "valid" | "invalid" | "empty"
```

## CellState

Each editable cell keeps `raw`, the resolved `value`, and `status` apart. A pasted value that does not match stays visible, so the user can fix it.

```ts
interface CellState<T> {
  raw: string
  value: T | null
  status: CellStatus
  /** Tooltip when invalid. */
  error?: string
}
```

## CellPosition

A cell is addressed by **row id** and **column id**, not display index. Focus and selection then survive filter, sort, and reorder.

```ts
interface CellPosition {
  rowId: string
  columnId: string
}
```

## CopiedRange

The copy outline (marching ants). It is stored by id: `Set` membership plus the edge ids.

```ts
interface CopiedRange {
  rowIds: Set<string>
  firstRowId: string
  lastRowId: string
  columnIds: Set<string>
  firstColumnId: string
  lastColumnId: string
}
```

## SelectionBounds

The selection rectangle, edges included, in **display** space (indices after filter and sort).

```ts
interface SelectionBounds {
  minRow: number
  maxRow: number
  minColIndex: number
  maxColIndex: number
}
```

## GridRow

```ts
interface GridRow {
  id: string
  [columnId: string]: CellState<string> | string
}
```

## Helpers

| Helper           | Role                                     |
| ---------------- | ---------------------------------------- |
| `emptyCell<T>()` | Blank cell with `status: "empty"`        |
| `isCellInBounds` | Inclusive membership in selection bounds |
