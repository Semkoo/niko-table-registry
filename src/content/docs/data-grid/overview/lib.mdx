## Cell props

The shared props contract for every typed cell.

<div className="not-content mb-4 flex items-center gap-2">
  <DocsLink href={`${GITHUB_REPO_URL}/blob/main/src/components/niko-table/grid/cells/cell-props.ts`} external>Source Code ↗</DocsLink>

- `CellEditorProps` is what `DataGridCell` passes to its render prop: focus and edit flags, commit helpers, and the current `CellState`.
- `GridComboboxOption` is the shape of searchable dropdown options (`label` / `value`).

| Export             | Role                                               |
| ------------------ | -------------------------------------------------- |
| `CELL_HEIGHT`      | Default row/cell height (`36`)                     |
| `cellTriggerClass` | Classnames for the display trigger (status chrome) |

Use these in a custom editor so it lines up with the built-in cells.

## Clipboard helpers

Exported from the clipboard hook. `DataGridClipboard` uses them:

| Helper               | Role                                  |
| -------------------- | ------------------------------------- |
| `parseTsv`           | Parse clipboard text into a 2D matrix |
| `serializeSelection` | Selection → TSV for copy              |

## Feature constants

From `data-grid-features.tsx`. They control edge auto-scroll while you drag fill or move:

| Constant          | Default | Role                         |
| ----------------- | ------- | ---------------------------- |
| `GRID_EDGE_ZONE`  | `36`    | Px near edge to start scroll |
| `GRID_EDGE_SPEED` | `14`    | Scroll step                  |
| `clampGridIndex`  | -       | Clamp display indices        |
