This example puts filter chips with live counts (for example "Status: Active 12") next to the search bar. Use it when users should see which values exist before they filter. `DataTableFacetedFilter` reads the counts from the current row model.

## Introduction

Each filter shows its options with counts. Users see what they can filter by and how many items match each option.

## Faceted Filter Component

### DataTableFacetedFilter

This component shows the available options with counts.

**Props:**

| Name                  | Type                   | Default     | Description                                                                                     |
| --------------------- | ---------------------- | ----------- | ----------------------------------------------------------------------------------------------- |
| `accessorKey`         | `keyof TData & string` | -           | The column key to filter (required)                                                             |
| `title`               | `string`               | -           | Optional label. Defaults to the column `meta.label` or the accessor name                        |
| `options`             | `Option[]`             | -           | Static options. If omitted and column meta allows it, options are generated                     |
| `multiple`            | `boolean`              | -           | Allow several selections (default depends on the column variant)                                |
| `showCounts`          | `boolean`              | `true`      | Show counts next to options                                                                     |
| `dynamicCounts`       | `boolean`              | `true`      | Counts follow the filtered rows                                                                 |
| `limitToFilteredRows` | `boolean`              | `!multiple` | Show only options from filtered rows (not all rows). On for single-select, off for multi-select |

### limitToFilteredRows

`limitToFilteredRows` decides whether the filter shows options from all data or only from the filtered rows.

**When `limitToFilteredRows={true}` (the default for single-select):**

- Options come from rows that match the other active filters.
- Good for filters like "Brand" or "Rating", where you only want relevant options.
- Example: filter by "Category: Electronics" and the Brand filter only shows brands in Electronics.

**When `limitToFilteredRows={false}`:**

- Options come from all rows, whatever the other filters say.
- Good for filters like "Category", where you want to see every category.
- Example: the Category filter always shows all categories, even when other filters are active.

```tsx showLineNumbers
// Category: Show all options (not limited by other filters)
<DataTableFacetedFilter
  accessorKey="category"
  title="Category"
  options={categoryOptions}
  multiple
  limitToFilteredRows={false} // Always show all categories
/>

// Brand: Show only brands from filtered rows
<DataTableFacetedFilter
  accessorKey="brand"
  title="Brand"
  multiple
  limitToFilteredRows={true} // Only show brands from current filter results
/>
```

```tsx showLineNumbers
// Auto-generated when meta.autoOptions or meta.options are set appropriately
<DataTableFacetedFilter accessorKey="category" multiple />
```

## Filter Functions

**Note:** Most tables do not need a custom `filterFn`. The default `extendedFilter` already handles the `ExtendedColumnFilter` format. Add your own only for special filter logic.

A custom `filterFn` works as you write it:

```tsx showLineNumbers
{
  accessorKey: "category",
  enableColumnFilter: true,
  // Custom filter function (optional - default works for most cases)
  filterFn: (row, id, filterValue: string[]) => {
    if (!filterValue?.length) return true
    const rowValue = String(row.getValue(id))
    return filterValue.includes(rowValue)
  },
}
```

**Auto-applied filter functions:**

When you set `meta.variant`, the matching `filterFn` is applied for you:

- **`variant: "range"`** gets `numberRangeFilter` (numeric ranges like price)
- **`variant: "date"`** or **`variant: "dateRange"`** gets `dateRangeFilter` (dates)

```tsx showLineNumbers
{
  accessorKey: "price",
  meta: {
    label: "Price",
    variant: "range", // Auto-applies numberRangeFilter
    unit: "$",
  },
  // No need to define filterFn - it's auto-applied!
}
```

Allow several selections with the `multiple` prop:


## Controlled State

Hold the filter state yourself and pass it in:

```tsx showLineNumbers
import { useState } from "react"
import type {
  PaginationState,
  SortingState,
  ColumnFiltersState,
  ColumnVisibilityState,
} from "@tanstack/react-table"

export function ControlledFacetedFilterTable({ data }: { data: Product[] }) {
  const [globalFilter, setGlobalFilter] = useState<string | object>("")
  const [sorting, setSorting] = useState<SortingState>([])
  const [columnFilters, setColumnFilters] = useState<ColumnFiltersState>([])
  const [columnVisibility, setColumnVisibility] = useState<ColumnVisibilityState>({})
  const [pagination, setPagination] = useState<PaginationState>({
    pageIndex: 0,
    pageSize: 10,
  })

  return (
    <DataTableRoot
      data={data}
      columns={columns}
      state={{
        globalFilter,
        sorting,
        columnFilters,
        columnVisibility,
        pagination,
      }}
      onGlobalFilterChange={value => {
        setGlobalFilter(value)
        setPagination(prev => ({ ...prev, pageIndex: 0 }))
      }}
      onSortingChange={setSorting}
      onColumnFiltersChange={filters => {
        setColumnFilters(filters)
        setPagination(prev => ({ ...prev, pageIndex: 0 }))
      }}
      onColumnVisibilityChange={setColumnVisibility}
      onPaginationChange={setPagination}
    >
      <DataTableToolbarSection className="w-full flex-col justify-between gap-2">
        <DataTableToolbarSection className="px-0">
          <DataTableSearchFilter placeholder="Search products..." />
          <DataTableViewMenu />
        </DataTableToolbarSection>
        <DataTableToolbarSection className="flex-wrap px-0">
          <DataTableFacetedFilter
            accessorKey="category"
            multiple
            limitToFilteredRows={false}
          />
          <DataTableFacetedFilter accessorKey="brand" limitToFilteredRows />
          <DataTableSliderFilter accessorKey="price" />
          <DataTableDateFilter accessorKey="releaseDate" multiple />
          <DataTableClearFilter />
        </DataTableToolbarSection>
      </DataTableToolbarSection>

      <DataTable>
        <DataTableHeader />
        <DataTableBody>
          <DataTableEmptyBody />
        </DataTableBody>
      </DataTable>

      <DataTablePagination />
    </DataTableRoot>
  )
}
```

## When to Use

**✅ Use Faceted Filter Table when:**

- You have categorical data (categories, tags, statuses)
- Users need to see the options and counts
- You want inline, visible filters
- Users often pick several options

**❌ Consider other options when:**

- You need rule-based filtering: use [Advanced Table](/examples/advanced-table/)
- You prefer dropdown filters: use [Advanced Table](/examples/advanced-table/)
- You only need search: use [Search Table](/examples/search-table/)
