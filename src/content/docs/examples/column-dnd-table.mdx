Users drag column headers to reorder columns. `DataTableColumnDndProvider` does this on top of `@dnd-kit`. Use it when people want their own column layout.

Unlike row DnD, column DnD works with sorting, filtering and virtualization. Column order does not depend on the rows.

## Virtualized Column DnD

For large datasets, use `DataTableVirtualizedDndHeader` and `DataTableVirtualizedDndColumnBody`. They combine row virtualization with column drag-and-drop.

- The `<DataTableColumnResize />` marker works the same way.
- Drag a header to reorder.
- Drag the edge grip to resize. The grip stops propagation, so it does not start a reorder.

## Introduction

Column DnD lets users reorder columns by dragging headers. It uses `@dnd-kit` and small composable pieces, in the shadcn/ui open-code style.

## Installation

Install the DataTable core and the column DnD add-ons. `data-table-view-dnd-menu` and `data-table-search-filter` give you the example toolbar:

## Basic Column DnD

Three pieces work together:

1. **`DataTableColumnDndProvider`**: wraps the table in a horizontal DnD context
2. **`DataTableDndHeader`**: renders headers as draggable items
3. **`DataTableDndColumnBody`**: cells follow the column being dragged

```tsx showLineNumbers title="column-dnd.tsx"
import {
  DataTableDndHeader,
  DataTableDndColumnBody,
} from "@/components/niko-table/core/data-table-column-dnd-structure"

const [columnOrder, setColumnOrder] = React.useState<string[]>(() =>
  columns.map(c => c.id as string),
)

return (
  <DataTableRoot
    data={data}
    columns={columns}
    state={{ columnOrder }}
    onColumnOrderChange={setColumnOrder}
  >
    <DataTableColumnResize />
    <DataTableColumnDndProvider
      columnOrder={columnOrder}
      onColumnOrderChange={setColumnOrder}
    >
      <DataTable>
        <DataTableDndHeader />
        <DataTableDndColumnBody />
      </DataTable>
    </DataTableColumnDndProvider>
  </DataTableRoot>
)
```

## Two Reorder Surfaces, One State

`DataTableViewDndMenu` is the View menu with drag-to-reorder. It shares the same `columnOrder` state as the header drag. Users get two ways to reorder. Visibility toggles and a Reset button sit in the same dropdown:

```tsx showLineNumbers title="column-dnd.tsx"
<DataTableToolbarSection className="justify-between">
  <DataTableSearchFilter placeholder="Search employees..." />
  <DataTableViewDndMenu
    columnOrder={columnOrder}
    onColumnOrderChange={setColumnOrder}
    onReset={() => setColumnOrder(initialColumnOrder)}
  />
</DataTableToolbarSection>
```

Do not need drag-to-reorder in the menu? Use [`DataTableViewMenu`](/niko-table/overview/components#datatableviewmenu) instead. It skips the `@dnd-kit/*` bundle.

## Key Points

- **Give every column an `id`.** The grid needs it to track column order.
- **Pass `columnOrder` to both** `DataTableRoot` and `DataTableColumnDndProvider`. Also pass it to `DataTableViewDndMenu` if you use it.
- **Headers are draggable by default.** Grab any header to reorder.
- **Safe with sorting and filtering.** Column order does not depend on data order, unlike [Row DnD](/examples/row-dnd-table/).
- **One shared state.** `DataTableViewDndMenu` and the header drag stay in sync.

## When to Use

**✅ Use Column DnD when:**

- Users want to customize the table layout
- Different users want different column orders
- You are building configurable dashboards

**❌ Consider other options when:**

- Column order is fixed by design
- The table has very few columns
