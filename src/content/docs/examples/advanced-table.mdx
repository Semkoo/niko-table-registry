This example combines `DataTableFilterMenu` and `DataTableSortMenu` into a query builder. Use it when users need to stack several typed filter rules (text, number, date, faceted) and join them with AND or OR.

State stays local. Use the [Advanced Nuqs Table](/examples/advanced-nuqs-table/) if you also need the URL to hold it.

## Introduction

Users can:

- Add several filter rules with `DataTableFilterMenu`.
- Join the rules with AND or OR.
- Manage sorting with `DataTableSortMenu`.

## Filter Components

### DataTableFilterMenu

This menu lets users build filters from several rules.

**Props:**

| Name                  | Type                                                | Default      | Description                                                               |
| --------------------- | --------------------------------------------------- | ------------ | ------------------------------------------------------------------------- |
| `autoOptions`         | `boolean`                                           | `true`       | Generate options for select and multiSelect columns                       |
| `showCounts`          | `boolean`                                           | `true`       | Show counts beside each option                                            |
| `dynamicCounts`       | `boolean`                                           | `true`       | Counts already recompute in the provider. The prop is kept for API parity |
| `limitToFilteredRows` | `boolean`                                           | `true`       | Build options from filtered rows only (not all rows)                      |
| `includeColumns`      | `string[]`                                          | -            | Only build options for these column ids                                   |
| `excludeColumns`      | `string[]`                                          | -            | Skip these column ids                                                     |
| `limitPerColumn`      | `number`                                            | -            | Max generated options per column                                          |
| `mergeStrategy`       | `"preserve" \| "augment" \| "replace"`              | `"preserve"` | How to treat existing static options                                      |
| `filters?`            | `ExtendedColumnFilter[]`                            | -            | Filters (controlled mode)                                                 |
| `onFiltersChange?`    | `(filters: ExtendedColumnFilter[] \| null) => void` | -            | Called when filters change                                                |
| `className`           | `string`                                            | -            | Additional CSS classes                                                    |

**Merge Strategy:**

- **`preserve`**: keep your options as they are (default)
- **`augment`**: add counts to the values in your static options
- **`replace`**: swap your static options for the generated ones

```tsx showLineNumbers
<DataTableFilterMenu
  autoOptions
  dynamicCounts
  showCounts
  limitToFilteredRows={true}
  mergeStrategy="augment"
/>
```

## Column Meta for Filters

Set the filter fields in your column definitions:

```tsx showLineNumbers
{
  accessorKey: "category",
  meta: {
    label: "Category",
    variant: "select",
    options: [
      { label: "Electronics", value: "electronics" },
      { label: "Clothing", value: "clothing" },
    ],
  },
  enableColumnFilter: true,
}
```

**Supported variants:**

- **`"text"`**: text input
- **`"select"`**: dropdown (needs `options`)
- **`"multiSelect"`**: dropdown with several choices
- **`"number"`**: number input (optional `unit` to show)
- **`"range"`**: numeric range slider (applied automatically for `number` with `meta.range`)
- **`"boolean"`**: checkbox
- **`"date"`**: single date picker
- **`"dateRange"`**: date range picker (applied automatically when `DataTableDateFilter` has `multiple={true}`)

**Auto-applied filter functions:**

When you set `meta.variant`, the matching `filterFn` is applied for you:

- **`variant: "range"`** gets `numberRangeFilter` (numeric ranges like price)
- **`variant: "date"`** or **`variant: "dateRange"`** gets `dateRangeFilter` (dates)

A custom `filterFn` overrides the automatic one.

## Controlled State

Hold the table state yourself and pass it in:

```tsx showLineNumbers
import { useState } from "react"
import type {
  PaginationState,
  SortingState,
  ColumnFiltersState,
} from "@tanstack/react-table"
import type { ExtendedColumnFilter } from "@/components/niko-table/types"

export function ControlledAdvancedTable({ data }: { data: Product[] }) {
  const [globalFilter, setGlobalFilter] = useState<string | object>("")
  const [sorting, setSorting] = useState<SortingState>([])
  const [columnFilters, setColumnFilters] = useState<ColumnFiltersState>([])
  const [pagination, setPagination] = useState<PaginationState>({
    pageIndex: 0,
    pageSize: 10,
  })

  const handleFiltersChange = (
    filters: ExtendedColumnFilter<Product>[] | null,
  ) => {
    if (!filters || filters.length === 0) {
      setColumnFilters([])
    } else {
      setColumnFilters(
        filters.map(filter => ({
          id: filter.id,
          value: filter,
        })),
      )
    }
  }

  return (
    <DataTableRoot
      data={data}
      columns={columns}
      config={{
        enablePagination: true,
        enableSorting: true,
        enableMultiSort: true,
        enableFilters: true,
      }}
      state={{
        globalFilter,
        sorting,
        columnFilters,
        pagination,
      }}
      onGlobalFilterChange={setGlobalFilter}
      onSortingChange={setSorting}
      onColumnFiltersChange={setColumnFilters}
      onPaginationChange={setPagination}
    >
      <DataTableToolbarSection>
        <DataTableToolbarSection className="px-0">
          <DataTableSearchFilter placeholder="Search products..." />
          <DataTableViewMenu />
        </DataTableToolbarSection>
        <DataTableToolbarSection className="px-0">
          <DataTableSortMenu className="ml-auto" />
          <DataTableFilterMenu
            filters={[]}
            onFiltersChange={handleFiltersChange}
          />
        </DataTableToolbarSection>
      </DataTableToolbarSection>
      <DataTable>
        <DataTableHeader />
        <DataTableBody>
          <DataTableEmptyBody />
        </DataTableBody>
      </DataTable>
      <DataTablePagination />
    </DataTableRoot>
  )
}
```

## When to Use

**✅ Use Advanced Table when:**

- Users need rule-based filtering
- You want a visual filter and sort UI
- Several filter conditions must be combined
- You want a drag-and-drop sort UI
- You manage filter state outside the table

**❌ Consider other options when:**

- Simple filtering is enough: use [Faceted Filter Table](/examples/faceted-filter-table/)
- You prefer inline filters: use [Advanced Inline Filter Table](/examples/advanced-inline-table/)
- You need filters kept in the URL: use [Advanced Nuqs Table](/examples/advanced-nuqs-table/)
