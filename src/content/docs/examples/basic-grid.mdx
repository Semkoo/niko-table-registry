This is the smallest useful Niko Grid. Start here when you want an editable table with the least code.

It uses `useDataGrid`, `<DataGrid>` and `GridTextCell`. You get:

- Keyboard navigation
- Undo and redo
- A virtualized body (only visible rows render)

Clipboard, fill, toolbar and row menu are optional children. The demo mounts the common ones. Leave out what you do not need.

This page is also the model for new grid examples: see [Documentation Guidelines](/contributing/documentation-guidelines/).

## What’s included

| Piece            | Role                                                  |
| ---------------- | ----------------------------------------------------- |
| `useDataGrid`    | Headless rows, focus, edit lifecycle, undo/redo       |
| `<DataGrid>`     | Keyboard nav + selection around `DataTable`           |
| `<DataGridCell>` | Id-addressed cell wrapper (not TanStack `row.index`)  |
| `GridTextCell`   | Text editor (display shell; editor mounts on edit)    |
| Virtualized body | Needs a fixed-height scroll container                 |
| Opt-in children  | Demo mounts clipboard, fill handle, toolbar, row menu |

## Composition

```tsx showLineNumbers
const grid = useDataGrid({
  columnIds: ["task", "assignee", "status"],
  createEmptyRow,
  initialRows,
})

<DataTableRoot data={grid.rows} columns={columns} getRowId={(r) => r.id}>
  <DataGrid grid={grid}>
    <DataTable maxHeight={360}>
      <DataTableVirtualizedHeader />
      <DataTableVirtualizedBody estimateSize={37} />
    </DataTable>
  </DataGrid>
</DataTableRoot>
```

Column `cell` renderers wrap editors in `<DataGridCell row={…} columnId={…}>`. Cells are found by row id, so focus and edits stay correct after you sort or filter.

<Aside type="tip">
  Mount only what you need. Clipboard, fill and move are children of `<DataGrid>`. See [Composed Grid](/examples/composed-grid/).
</Aside>
