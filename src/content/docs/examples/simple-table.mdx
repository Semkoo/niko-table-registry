The smallest install: only `@niko-table/data-table`, no add-ons. It renders an accessible `<thead>` and `<tbody>` and nothing more: no pagination, sort, or filters. Use it when the dataset is short and static.

## Introduction

The Simple Table is the most basic setup. It shows your data in a clean, accessible table with no pagination, filtering, or sorting. Use it for small datasets (under 50 rows) or when you only need to display data.

## Installation

Install the DataTable core:

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table" />

> First time using `@niko-table`? See the [Installation Guide](/getting-started/installation/#configure-the-registry) to set up the registry.

For optional add-ons (pagination, filters, virtualization, etc.) and manual copy-paste, see the [Installation Guide](/getting-started/installation/).

## Prerequisites

We are going to build a table of users. Here's what our data looks like:

```tsx showLineNumbers
type User = {
  id: string
  name: string
  email: string
  status: "active" | "inactive"
}

const data: User[] = [
  { id: "1", name: "John Doe", email: "john@example.com", status: "active" },
  { id: "2", name: "Jane Smith", email: "jane@example.com", status: "active" },
  {
    id: "3",
    name: "Bob Johnson",
    email: "bob@example.com",
    status: "inactive",
  },
]
```

## Basic Table

Start with a basic table.

### Column Definitions

First, define the columns.

```tsx showLineNumbers title="columns.tsx"
"use client"

import type { DataTableColumnDef } from "@/components/niko-table/types"

export type User = {
  id: string
  name: string
  email: string
  status: "active" | "inactive"
}

export const columns: DataTableColumnDef<User>[] = [
  {
    accessorKey: "name",
    header: "Name",
  },
  {
    accessorKey: "email",
    header: "Email",
  },
  {
    accessorKey: "status",
    header: "Status",
  },
]
```

### `<DataTable />` component

Next, create a `<DataTable />` component to render the table.

```tsx showLineNumbers title="simple-table.tsx"
"use client"

import { DataTableRoot } from "@/components/niko-table/core/data-table-root"
import { DataTable } from "@/components/niko-table/core/data-table"
import {
  DataTableHeader,
  DataTableBody,
  DataTableSkeleton,
  DataTableEmptyBody,
} from "@/components/niko-table/core/data-table-structure"
import type { DataTableColumnDef } from "@/components/niko-table/types"

type User = {
  id: string
  name: string
  email: string
  status: "active" | "inactive"
}

const columns: DataTableColumnDef<User>[] = [
  {
    accessorKey: "name",
    header: "Name",
  },
  {
    accessorKey: "email",
    header: "Email",
  },
  {
    accessorKey: "status",
    header: "Status",
  },
]

export function SimpleTable({ data }: { data: User[] }) {
  return (
    <DataTableRoot data={data} columns={columns}>
      <DataTable>
        <DataTableHeader />
        <DataTableBody>
          <DataTableSkeleton />
          <DataTableEmptyBody />
        </DataTableBody>
      </DataTable>
    </DataTableRoot>
  )
}
```

## Cell Formatting

Now format the status cell to show colors.

```tsx showLineNumbers title="columns.tsx"
export const columns: DataTableColumnDef<User>[] = [
  {
    accessorKey: "status",
    header: "Status",
    cell: ({ row }) => {
      const status = row.getValue("status") as string
      return (
        <span
          className={status === "active" ? "text-green-600" : "text-gray-400"}
        >
          {status}
        </span>
      )
    },
  },
]
```

Use the same approach to format other cells.

## Loading State

Show a loading skeleton while data is being fetched:

```tsx showLineNumbers
export function SimpleTable({
  data,
  isLoading,
}: {
  data: User[]
  isLoading?: boolean
}) {
  return (
    <DataTableRoot data={data} columns={columns} isLoading={isLoading}>
      <DataTable>
        <DataTableHeader />
        <DataTableBody>
          <DataTableSkeleton />
          <DataTableEmptyBody />
        </DataTableBody>
      </DataTable>
    </DataTableRoot>
  )
}
```

`DataTableSkeleton` shows automatically when `isLoading` is `true`.

## Empty State

`DataTableEmptyBody` shows automatically when there is no data, or when filters return no results.

## When to Use

**✅ Use Simple Table when:**

- You have a small dataset (under 50 rows)
- You don't need user interaction (sorting, filtering)
- You want the fastest, simplest setup
- You're building a prototype or MVP

**❌ Don't use Simple Table when:**

- You have more than 50 rows (use [Basic Table](/examples/basic-table/) with pagination)
- Users need to search or filter (use [Search Table](/examples/search-table/))
- Users need to sort columns (use [Basic Table](/examples/basic-table/))
