This is the usual starting point. Use it for most app tables. It has three add-ons:

- **Pagination:** `DataTablePagination`
- **Sorting per column:** `DataTableColumnSort`
- **Show and hide columns:** `DataTableViewMenu`

## Introduction

The Basic Table builds on the Simple Table. It adds pagination, sorting and column visibility.

## Installation

Install the DataTable core and add-ons for this example:

<CliCommandCode action="run" command="shadcn@latest add @niko-table/data-table @niko-table/data-table-pagination @niko-table/data-table-view-menu @niko-table/data-table-column-sort" />

> First time using `@niko-table`? See the [Installation Guide](/getting-started/installation/#configure-the-registry) to set up the registry.

For other add-ons or manual copy-paste, see the [Installation Guide](/getting-started/installation/).

## Prerequisites

You build a product table. This is the data:

```tsx showLineNumbers
type Product = {
  id: string
  name: string
  category: string
  price: number
  stock: number
}

const data: Product[] = [
  { id: "1", name: "Laptop", category: "Electronics", price: 999, stock: 50 },
  { id: "2", name: "Mouse", category: "Electronics", price: 29, stock: 150 },
  // ...
]
```

## Basic Table

Start with a basic table that has pagination and sorting.

### Column Definitions

Define the columns with sortable headers.

```tsx showLineNumbers title="columns.tsx"
"use client"

import { DataTableColumnHeader } from "@/components/niko-table/components/data-table-column-header"
import { DataTableColumnTitle } from "@/components/niko-table/components/data-table-column-title"
import { DataTableColumnSortMenu } from "@/components/niko-table/components/data-table-column-sort"
import type { DataTableColumnDef } from "@/components/niko-table/types"

export type Product = {
  id: string
  name: string
  category: string
  price: number
  stock: number
}

export const columns: DataTableColumnDef<Product>[] = [
  {
    accessorKey: "name",
    header: () => (
      <DataTableColumnHeader>
        <DataTableColumnTitle />
        <DataTableColumnSortMenu />
      </DataTableColumnHeader>
    ),
    meta: { label: "Product" },
  },
  {
    accessorKey: "category",
    header: () => (
      <DataTableColumnHeader>
        <DataTableColumnTitle />
        <DataTableColumnSortMenu />
      </DataTableColumnHeader>
    ),
    meta: { label: "Category" },
  },
  {
    accessorKey: "price",
    header: () => (
      <DataTableColumnHeader>
        <DataTableColumnTitle />
        <DataTableColumnSortMenu />
      </DataTableColumnHeader>
    ),
    meta: { label: "Price" },
    cell: ({ row }) => {
      const price = parseFloat(row.getValue("price"))
      return <div className="font-medium">${price.toFixed(2)}</div>
    },
  },
  {
    accessorKey: "stock",
    header: () => (
      <DataTableColumnHeader>
        <DataTableColumnTitle />
        <DataTableColumnSortMenu />
      </DataTableColumnHeader>
    ),
    meta: { label: "Stock" },
  },
]
```

### `<DataTable />` component

Create a `<DataTable />` with pagination and sorting turned on.

```tsx showLineNumbers title="basic-table.tsx"
"use client"

import { DataTableRoot } from "@/components/niko-table/core/data-table-root"
import { DataTable } from "@/components/niko-table/core/data-table"
import {
  DataTableHeader,
  DataTableBody,
} from "@/components/niko-table/core/data-table-structure"
import { DataTableToolbarSection } from "@/components/niko-table/components/data-table-toolbar-section"
import { DataTablePagination } from "@/components/niko-table/components/data-table-pagination"
import { DataTableViewMenu } from "@/components/niko-table/components/data-table-view-menu"
import { DataTableColumnHeader } from "@/components/niko-table/components/data-table-column-header"
import { DataTableColumnTitle } from "@/components/niko-table/components/data-table-column-title"
import { DataTableColumnSortMenu } from "@/components/niko-table/components/data-table-column-sort"
import type { DataTableColumnDef } from "@/components/niko-table/types"

type Product = {
  id: string
  name: string
  category: string
  price: number
  stock: number
}

const columns: DataTableColumnDef<Product>[] = [
  {
    accessorKey: "name",
    header: () => (
      <DataTableColumnHeader>
        <DataTableColumnTitle />
        <DataTableColumnSortMenu />
      </DataTableColumnHeader>
    ),
    meta: { label: "Product" },
  },
  {
    accessorKey: "category",
    header: () => (
      <DataTableColumnHeader>
        <DataTableColumnTitle />
        <DataTableColumnSortMenu />
      </DataTableColumnHeader>
    ),
    meta: { label: "Category" },
  },
  {
    accessorKey: "price",
    header: () => (
      <DataTableColumnHeader>
        <DataTableColumnTitle />
        <DataTableColumnSortMenu />
      </DataTableColumnHeader>
    ),
    meta: { label: "Price" },
    cell: ({ row }) => {
      const price = parseFloat(row.getValue("price"))
      return <div className="font-medium">${price.toFixed(2)}</div>
    },
  },
  {
    accessorKey: "stock",
    header: () => (
      <DataTableColumnHeader>
        <DataTableColumnTitle />
        <DataTableColumnSortMenu />
      </DataTableColumnHeader>
    ),
    meta: { label: "Stock" },
  },
]

export function BasicTable({ data }: { data: Product[] }) {
  return (
    <DataTableRoot
      data={data}
      columns={columns}
      config={{
        enablePagination: true,
        enableSorting: true,
        enableMultiSort: true,
        initialPageSize: 10,
      }}
    >
      <DataTableToolbarSection className="justify-between">
        <h2 className="text-lg font-semibold">Products</h2>
        <DataTableViewMenu />
      </DataTableToolbarSection>

      <DataTable>
        <DataTableHeader />
        <DataTableBody />
      </DataTable>

      <DataTablePagination pageSizeOptions={[5, 10, 20]} />
    </DataTableRoot>
  )
}
```

## Pagination

Set `enablePagination: true` in the config to turn pagination on. `DataTablePagination` gives you:

- Previous and next buttons
- A page size selector
- Current page info (e.g., "1-10 of 100")

### Custom Page Sizes

Change the page sizes users can pick:

```tsx showLineNumbers
<DataTablePagination pageSizeOptions={[10, 25, 50, 100]} />
```

## Sorting

Use `DataTableColumnHeader` in your column definitions to turn sorting on. Click a column header to sort by it.

### Multi-Column Sorting

Hold `Shift` and click several headers to sort by several columns:

```tsx showLineNumbers
<DataTableRoot
  data={data}
  columns={columns}
  config={{
    enableMultiSort: true, // Enable multi-column sorting
  }}
>
  {/* ... */}
</DataTableRoot>
```

### Disable Sorting

Turn sorting off for one column:

```tsx showLineNumbers
{
  accessorKey: "id",
  header: "ID",
  enableSorting: false, // This column cannot be sorted
}
```

## Column Visibility

`DataTableViewMenu` adds a dropdown to show and hide columns:

```tsx showLineNumbers
<DataTableToolbarSection className="justify-between">
  <h2 className="text-lg font-semibold">Products</h2>
  <DataTableViewMenu />
</DataTableToolbarSection>
```

### Disable Column Hiding

Stop certain columns from being hidden:

```tsx showLineNumbers
{
  accessorKey: "id",
  header: "ID",
  enableHiding: false, // This column cannot be hidden
}
```

## Controlled State

Hold the table state yourself and pass it in:

```tsx showLineNumbers
import { useState } from "react"
import type {
  PaginationState,
  SortingState,
  ColumnVisibilityState,
} from "@tanstack/react-table"

export function ControlledBasicTable({ data }: { data: Product[] }) {
  const [pagination, setPagination] = useState<PaginationState>({
    pageIndex: 0,
    pageSize: 10,
  })
  const [sorting, setSorting] = useState<SortingState>([])
  const [columnVisibility, setColumnVisibility] = useState<ColumnVisibilityState>({})

  return (
    <DataTableRoot
      data={data}
      columns={columns}
      state={{
        pagination,
        sorting,
        columnVisibility,
      }}
      onPaginationChange={setPagination}
      onSortingChange={setSorting}
      onColumnVisibilityChange={setColumnVisibility}
    >
      <DataTableToolbarSection className="justify-between">
        <h2 className="text-lg font-semibold">Products</h2>
        <DataTableViewMenu />
      </DataTableToolbarSection>

      <DataTable>
        <DataTableHeader />
        <DataTableBody />
      </DataTable>

      <DataTablePagination />
    </DataTableRoot>
  )
}
```

## When to Use

**✅ Use Basic Table when:**

- You have 50+ rows that need pages
- Users need to sort
- You want show/hide column controls
- You do not need search or filters

**❌ Consider other options when:**

- You have fewer than 50 rows: use [Simple Table](/examples/simple-table/)
- Users need to search: use [Search Table](/examples/search-table/)
- You need advanced filters: use [Advanced Table](/examples/advanced-table/)
