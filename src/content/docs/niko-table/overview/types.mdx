## Core Types

### Option

An option in a select or multi-select filter.

```tsx
interface Option {
  label: string
  value: string
  count?: number
  icon?: React.ComponentType<{ className?: string }>
}
```

### FilterVariant

Sets which UI control a filter uses.

```tsx
type FilterVariant =
  | "text"
  | "number"
  | "range"
  | "date"
  | "dateRange"
  | "select"
  | "multiSelect"
  | "boolean"
```

### FilterOperator

Sets how a filter compares values.

```tsx
type FilterOperator =
  | "ilike"
  | "not.ilike"
  | "eq"
  | "neq"
  | "in"
  | "not.in"
  | "empty"
  | "not.empty"
  | "lt"
  | "lte"
  | "gt"
  | "gte"
  | "between"
  | "relative"
```

### JoinOperator

Sets how several filters combine.

```tsx
type JoinOperator = "and" | "or" | "mixed"
```

## Extended Types

### ExtendedColumnFilter

A column filter with extra metadata.

```tsx
interface ExtendedColumnFilter<TData> {
  id: Extract<keyof TData, string>
  value: string | string[]
  variant: FilterVariant
  operator: FilterOperator
  filterId: string
  joinOperator?: JoinOperator // Individual join operator for each filter
}
```

### ExtendedColumnSort

A column sort, used for URL state.

```tsx
interface ExtendedColumnSort<TData> {
  id: Extract<keyof TData, string>
  desc: boolean
}
```

### GlobalFilter

The global (search) filter value.

```tsx
type GlobalFilter = string | Record<string, unknown>
```

## Column Definition Types

### DataTableColumnDef

The column definition type. It has every TanStack Table `ColumnDef` property.

```tsx
type DataTableColumnDef<TData, TValue = unknown> = ColumnDef<
  DataTableFeatures,
  TData,
  TValue
>
```

For static columns, use [`createDataTableColumnHelper<TData>()`](/niko-table/overview/lib/#createdatatablecolumnhelper).

- **Same binding:** it pre-binds `DataTableFeatures`, like this alias.
- **Typed cells:** `getValue()` is typed.
- **Mixed value types:** helper results mix per-column value types. Pass them as `DataTableColumns<TData>` (what `DataTableRoot` accepts).
- **Plain arrays:** `DataTableColumnDef<TData>[]` fits dynamic columns and copy-paste examples better.

```tsx
import { createDataTableColumnHelper } from "@/components/niko-table/lib/data-table-features"

const columnHelper = createDataTableColumnHelper<Product>()
const columns = [
  columnHelper.accessor("price", {
    cell: ({ getValue }) => getValue().toFixed(2),
  }),
]
```

### DataTableColumns

The column array type for `DataTableRoot`. Helper columns each have their own `TValue`, so they do not fit `DataTableColumnDef<TData>[]` (its `TValue` defaults to `unknown`). Use this alias instead.

```tsx
type DataTableColumns<TData> = DataTableColumnDef<TData, any>[]
```

### ColumnMeta

Extra column metadata. It adds to TanStack Table's `ColumnMeta`.

```tsx
interface ColumnMeta<TData extends RowData, TValue> {
  // Display
  label?: string
  placeholder?: string

  // Filtering
  variant?: FilterVariant
  options?: Option[]
  range?: [number, number]
  autoOptions?: boolean
  autoOptionsFormat?: boolean
  /** Per-column label formatter for auto-derived faceted-filter options.
   *  Wins over `autoOptionsFormat`; ignored when caller passes explicit `options`. */
  formatOptionLabel?: (value: string) => string
  showCounts?: boolean
  dynamicCounts?: boolean
  mergeStrategy?: "preserve" | "augment" | "replace"

  // Formatting
  unit?: string
  icon?: React.ComponentType<{ className?: string }>

  // Layout
  /** Controls which column absorbs leftover row width (flex fill).
   *  Fill is on by default for resizable tables — the first non-pinned,
   *  resizable data column flexes automatically. Set `true` to make THIS
   *  column the one that fills instead of the default; set `false` to opt a
   *  column out of ever being auto-picked. Pure layout — never written to
   *  `columnSizing`. */
  flex?: boolean

  // Row Expansion
  expandedContent?: (row: TData) => React.ReactNode
}
```

### TableMeta

Extra table metadata. It adds to TanStack Table's `TableMeta`.

```tsx
interface TableMeta<TData extends RowData> {
  joinOperator?: JoinOperator
  hasIndividualJoinOperators?: boolean
  /** Turns flex fill off for the whole table. Flex fill (the first resizable
   *  data column absorbing leftover row width) is on by default when column
   *  resizing is enabled; set `true` for a wide table meant to scroll
   *  horizontally rather than fill its container. */
  disableFlexFill?: boolean
}
```

Pass table metadata through the **table-level** `meta` option on `DataTableRoot`, not a column's `meta`:

```tsx
<DataTableRoot data={data} columns={columns} meta={{ disableFlexFill: true }}>
```

`disableFlexFill` is read when the table options are built. Set it statically, not at runtime.

## Row Types

### DataTableRow

A row. Alias for TanStack Table's `Row`, bound to DataTable's features.

```tsx
type DataTableRow<TData> = Row<DataTableFeatures, TData>
```

### DataTableInstance

The table instance. Alias for TanStack Table's `Table`, bound to DataTable's features.

```tsx
type DataTableInstance<TData> = Table<DataTableFeatures, TData>
```

## Type Helpers

### ValueOf

Gets the literal values of a constant object.

```tsx
type ValueOf<T> = T[keyof T]
```

### JoinOperatorValues

The values of the `JOIN_OPERATORS` constant.

```tsx
type JoinOperatorValues = typeof JOIN_OPERATORS
```

### FilterOperatorValues

The values of the `FILTER_OPERATORS` constant.

```tsx
type FilterOperatorValues = typeof FILTER_OPERATORS
```

### FilterVariantValues

The values of the `FILTER_VARIANTS` constant.

```tsx
type FilterVariantValues = typeof FILTER_VARIANTS
```

## TanStack Table Module Augmentation

This module adds custom metadata to TanStack Table's types:

- **ColumnMeta**: adds label, placeholder, variant, options, `flex` (layout fill), and other filter metadata
- **TableMeta**: adds joinOperator and hasIndividualJoinOperators (filter logic), and `disableFlexFill` (layout)

TypeScript can then check and autocomplete column and table metadata.
