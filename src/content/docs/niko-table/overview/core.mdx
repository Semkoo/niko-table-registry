Core components are the base of every table. They set up the table, share context, and draw the structure.

### DataTableRoot

`DataTableRoot` gives every child component the table context. Always wrap your table in it.

- **Creates the table:** it calls `useTable` with the shared `features` object from `lib/data-table-features.ts` (TanStack Table v9).
- **Holds the state:** it manages table state.

<div className="not-content mb-4 flex items-center gap-2">
  <DocsLink href={`${GITHUB_REPO_URL}/blob/main/src/components/niko-table/core/data-table-root.tsx`} external>Source Code ↗</DocsLink>
  <DocsLink href="https://tanstack.com/table/latest/docs/framework/react/guide/migrating" external>Migrating to v9 ↗</DocsLink>
</div>

```tsx showLineNumbers
import { DataTableRoot } from "@/components/niko-table/core/data-table-root"

export function MyTable({ data }: { data: User[] }) {
  return (
    <DataTableRoot data={data} columns={columns}>
      {/* child components */}
    </DataTableRoot>
  )
}
```

#### Props

| Name        | Type                                    | Description                                        |
| ----------- | --------------------------------------- | -------------------------------------------------- |
| `children`  | `React.ReactNode`                       | Child components (required).                       |
| `data`      | `TData[]`                               | The data array to display in the table.            |
| `columns`   | `DataTableColumnDef<TData>[]`           | Column definitions array.                          |
| `table`     | `DataTableInstance<TData>`              | Pre-configured TanStack Table instance (optional). |
| `config`    | `DataTableConfig`                       | Configuration object for feature toggles.          |
| `isLoading` | `boolean`                               | Loading state for the table.                       |
| `getRowId`  | `(row: TData, index: number) => string` | Custom function to get row IDs.                    |
| `className` | `string`                                | Additional CSS classes.                            |
| `state`     | `Partial<TableState>`                   | Controlled table state (pagination, sorting, etc). |

#### Event Handlers

| Name                       | Type                                                | Description                            |
| -------------------------- | --------------------------------------------------- | -------------------------------------- |
| `onGlobalFilterChange`     | `(value: GlobalFilter) => void`                     | Called when global filter changes.     |
| `onPaginationChange`       | `(updater: Updater<PaginationState>) => void`       | Called when pagination changes.        |
| `onSortingChange`          | `(updater: Updater<SortingState>) => void`          | Called when sorting changes.           |
| `onColumnFiltersChange`    | `(updater: Updater<ColumnFiltersState>) => void`    | Called when column filters change.     |
| `onColumnVisibilityChange` | `(updater: Updater<ColumnVisibilityState>) => void` | Called when column visibility changes. |
| `onRowSelectionChange`     | `(updater: Updater<RowSelectionState>) => void`     | Called when row selection changes.     |
| `onExpandedChange`         | `(updater: Updater<ExpandedState>) => void`         | Called when expanded state changes.    |
| `onColumnPinningChange`    | `(updater: Updater<ColumnPinningState>) => void`    | Called when column pinning changes.    |
| `onColumnOrderChange`      | `(updater: Updater<ColumnOrderState>) => void`      | Called when column order changes.      |
| `onRowSelection`           | `(selectedRows: TData[]) => void`                   | Called with selected row data.         |

#### Config Object

The `config` prop takes a `DataTableConfig` object:

| Name                   | Type      | Default | Description                                                                                                     |
| ---------------------- | --------- | ------- | --------------------------------------------------------------------------------------------------------------- |
| `enablePagination`     | `boolean` | `false` | Turns on pagination. On automatically when `DataTablePagination` is used.                                       |
| `enableFilters`        | `boolean` | `false` | Turns on filtering. On automatically when filter components are used.                                           |
| `enableSorting`        | `boolean` | `false` | Turns on sorting. On automatically when sort components are used.                                               |
| `enableRowSelection`   | `boolean` | `false` | Enable row selection.                                                                                           |
| `enableMultiSort`      | `boolean` | `true`  | Enable multi-column sorting.                                                                                    |
| `enableGrouping`       | `boolean` | `false` | Turns on column grouping. On automatically when column group UI is used. Do not combine with tree `getSubRows`. |
| `enableExpanding`      | `boolean` | `false` | Enable row expansion.                                                                                           |
| `manualSorting`        | `boolean` | `false` | Enable server-side sorting.                                                                                     |
| `manualPagination`     | `boolean` | `false` | Enable server-side pagination.                                                                                  |
| `manualFiltering`      | `boolean` | `false` | Enable server-side filtering.                                                                                   |
| `pageCount`            | `number`  | -       | Total pages (required for server-side pagination).                                                              |
| `initialPageSize`      | `number`  | `10`    | Initial page size.                                                                                              |
| `initialPageIndex`     | `number`  | `0`     | Initial page index.                                                                                             |
| `autoResetPageIndex`   | `boolean` | `false` | Resets the page when filters or sorting change. Off by default (avoids flushSync warnings).                     |
| `autoResetExpanded`    | `boolean` | `false` | Auto-reset expanded rows on filter/sort change.                                                                 |
| `enableColumnResizing` | `boolean` | `false` | Turns on column resizing. On automatically when `DataTableColumnResize` is used.                                |

### DataTableProvider

The context provider `DataTableRoot` uses inside. Use it directly when you call `useTable` yourself and want to pass in your own table instance.

```tsx showLineNumbers
import { DataTableProvider } from "@/components/niko-table/core/data-table-context"
import { useTable } from "@tanstack/react-table"
import { features } from "@/components/niko-table/lib/data-table-features"

const table = useTable({ features, data, columns })

<DataTableProvider table={table} columns={columns} isLoading={false}>
  {/* child components can use useDataTable() */}
</DataTableProvider>
```

#### Props

| Name        | Type                          | Description                         |
| ----------- | ----------------------------- | ----------------------------------- |
| `table`     | `DataTableInstance<TData>`    | TanStack Table instance (required). |
| `columns`   | `DataTableColumnDef<TData>[]` | Column definitions (optional).      |
| `isLoading` | `boolean`                     | Loading state (optional).           |
| `children`  | `React.ReactNode`             | Child components.                   |

### DataTableContext

The raw React context object. Use it when you need to check whether a context exists (for example, to render conditionally).

```tsx showLineNumbers
import { DataTableContext } from "@/components/niko-table/core/data-table-context"
import { useContext } from "react"

const context = useContext(DataTableContext)
```

### DataTableBody

Draws the rows. Supports scroll events and row expansion.

<div className="not-content mb-4 flex items-center gap-2">
  <DocsLink href={`${GITHUB_REPO_URL}/blob/main/src/components/niko-table/core/data-table-structure.tsx`} external>Source Code ↗</DocsLink>

```tsx showLineNumbers
import {
  DataTableBody,
  DataTableSkeleton,
  DataTableEmptyBody,
} from "@/components/niko-table/core/data-table-structure"

<DataTableBody
  onScroll={e => console.log(`Scrolled ${e.percentage}%`)}
  onScrolledBottom={() => loadMore()}
>
  <DataTableSkeleton />
  <DataTableEmptyBody />
</DataTableBody>
```

#### Props

| Name               | Type                                                         | Default | Description                                                                                                                                                                          |
| ------------------ | ------------------------------------------------------------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `className`        | `string`                                                     | -       | Additional CSS classes.                                                                                                                                                              |
| `children`         | `React.ReactNode`                                            | -       | Child components (Skeleton, EmptyBody).                                                                                                                                              |
| `onScroll`         | `(event: ScrollEvent) => void`                               | -       | Scroll event handler.                                                                                                                                                                |
| `onScrolledTop`    | `() => void`                                                 | -       | Called when scrolled to top.                                                                                                                                                         |
| `onScrolledBottom` | `() => void`                                                 | -       | Called when scrolled to bottom.                                                                                                                                                      |
| `scrollThreshold`  | `number`                                                     | `50`    | Threshold for scroll events.                                                                                                                                                         |
| `onRowClick`       | `(row: TData, event: React.MouseEvent<HTMLElement>) => void` | -       | Called when a row is clicked.                                                                                                                                                        |
| `getRowMemoKey`    | `(row: TData) => string`                                     | -       | A per-row key for state kept outside the table (inline edits, optimistic updates). When it changes, only that row re-renders. See [Inline Edit Table](/examples/inline-edit-table/). |

> **Row memo invalidation:** all six body components use `React.memo` for speed.
>
> - Column toggle, reorder and pin already refresh rows (the `columnLayoutSignature` prop covers them).
> - If a column `cell` reads **external state** (inline edit drafts, optimistic updates), set `getRowMemoKey`. Then only the changed row re-renders.

#### ScrollEvent Type

The `ScrollEvent` object passed to `onScroll` contains:

| Property       | Type      | Description                       |
| -------------- | --------- | --------------------------------- |
| `scrollTop`    | `number`  | Current scroll position from top. |
| `scrollHeight` | `number`  | Total scrollable height.          |
| `clientHeight` | `number`  | Visible height of the container.  |
| `isTop`        | `boolean` | Whether scrolled to the top.      |
| `isBottom`     | `boolean` | Whether scrolled to the bottom.   |
| `percentage`   | `number`  | Scroll percentage (0-100).        |

### DataTableLoadingMore

A "loading more" row for infinite-scroll tables.

- **Shows:** at the end of the body while `isFetching` is `true`. Renders nothing when `false`.
- **Where:** a child of `DataTableBody`, next to `DataTableSkeleton` and `DataTableEmptyBody`.
- **Next page:** use `onScrolledBottom` on the body to fetch it.

<div className="not-content mb-4 flex items-center gap-2">
  <DocsLink href={`${GITHUB_REPO_URL}/blob/main/src/components/niko-table/core/data-table-structure.tsx`} external>Source Code ↗</DocsLink>
</div>

```tsx showLineNumbers
<DataTableBody
  onScrolledBottom={() => {
    if (hasMore && !isFetching) void loadMore()
  }}
>
  <DataTableSkeleton rows={10} />
  <DataTableEmptyBody />
  <DataTableLoadingMore isFetching={isFetching}>
    Loading more products...
  </DataTableLoadingMore>
</DataTableBody>
```

See [Infinite Scroll Table](/examples/infinite-scroll-table/) for a complete working example.

#### Props

| Name                | Type                                            | Default | Description                                                                                                                                                                  |

| `children`          | `React.ReactNode`                               | -       | Child components (VirtualizedSkeleton, VirtualizedEmptyBody).                                                                                                                |
| `estimateSize`      | `number`                                        | `34`    | Estimated row height in pixels.                                                                                                                                              |

### DnD Components

Pick the DnD components for your case:

| Use Case                     | Components                                                            |
| ---------------------------- | --------------------------------------------------------------------- |
| Row reorder (standard)       | `DataTableDndBody`                                                    |
| Column reorder (standard)    | `DataTableDndHeader` + `DataTableDndColumnBody`                       |
| Row reorder (virtualized)    | `DataTableVirtualizedDndBody`                                         |
| Column reorder (virtualized) | `DataTableVirtualizedDndHeader` + `DataTableVirtualizedDndColumnBody` |

Row and column DnD are **separate modules**. Installing one does not install the other. They replace `DataTableHeader` and `DataTableBody` directly.

### Virtualized DnD Components

Virtualized DnD is split by axis the same way. Registry: `data-table-virtualized-row-dnd` / `data-table-virtualized-column-dnd` (plus `data-table-virtualized` and the matching non-virtualized axis package).

#### DataTableVirtualizedDndBody

Virtualized body for **row** drag-and-drop. It pairs `@tanstack/react-virtual` (windowing) with `@dnd-kit/sortable` (dragging). Needs a `DataTableRowDndProvider` around it.
