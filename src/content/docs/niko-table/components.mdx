Build your table by nesting small components. They also mix with other shadcn/ui components.

**The code is yours. Change it whenever you need to.**

## Directory Structure

`DataTable*` components live in folders under `src/components/niko-table` (the folder the registry copies into your project):

- **`core/`**: the essentials (DataTableRoot, DataTable, context, structure components)
- **`components/`**: user-facing components that read the table from context via `useDataTable`
- **`filters/`**: core filter components that take a `table` prop (used by `components/`)
- **`hooks/`**: custom React hooks
- **`lib/`**: helper functions and constants
- **`types.ts`**: TypeScript types
- **`config/`**: settings and feature detection

These docs follow the same folders. Each section links to its source code.

## Documentation Sections

### [Core Components](/niko-table/overview/core/)

The building blocks. They set up the table, share context, and draw the basic structure.

**Components:**

- `DataTableRoot` - Provides table context and initializes TanStack Table
- `DataTable` - Main table container with scrolling behavior
- `DataTableHeader` - Table header with sortable columns
- `DataTableBody` - Table body with rows and scroll events
- `DataTableSkeleton` - Loading skeleton
- `DataTableEmptyBody` - Empty state component
- `DataTableLoading` - Loading indicator
- `DataTableErrorBoundary` - Error boundary for table
- Virtualized components for large datasets
- DnD structure components for drag-and-drop (row and column)
- Virtualized DnD components for drag-and-drop with virtualization

### [User-Facing Components](/niko-table/overview/components/)

Components that find the table on their own through `useDataTable`. Start here for most tables.

**Components:**

- `DataTableToolbarSection` - Container for filters and actions
- `DataTablePagination` - Full-featured pagination controls
- `DataTableSearchFilter` - Global search input with debouncing
- `DataTableFilterMenu` - Command palette-style filter interface
- `DataTableFacetedFilter` - Faceted filter for single/multiple selection
- `DataTableSortMenu` - Sort management with drag-and-drop
- `DataTableViewMenu` - Column visibility toggle
- `DataTableInlineFilter` - Inline filter toolbar
- `DataTableSliderFilter` - Slider filter for numeric ranges
- `DataTableDateFilter` - Date filter component
- `DataTableClearFilter` - Clear all filters button
- `DataTableExportButton` - Export to CSV button
- `DataTableColumnHeader` - Sortable column header
- `DataTableColumnFacetedFilterMenu` - Column-level faceted filter popover
- `DataTableColumnSliderFilterMenu` - Column-level slider filter popover
- `DataTableColumnDateFilterMenu` - Column-level date filter popover
- `DataTableAside` - Sidebar component
- `DataTableSelectionBar` - Bulk actions bar
- `DataTableEmptyState` - Empty state composition components
- `DataTableRowDndProvider` - Row DnD context provider
- `DataTableDraggableRow` - Wrapper for a draggable row (used with DataTableDndBody)
- `DataTableRowDragHandle` - Drag handle for row reordering
- `DataTableColumnDndProvider` - Column DnD context provider
- `DataTableDraggableHeader` - Draggable column header
- `DataTableDragAlongCell` - Cell that follows column drag

### [Filter Components](/niko-table/overview/filters/)

Filter components that take a `table` prop directly. The user-facing components use them inside. You can also use them on their own in custom components.

**Components:**

- `TableSearchFilter` - Core search filter
- `TablePagination` - Core pagination
- `TableFilterMenu` - Core filter menu
- `TableColumnFilterTrigger` - Core column filter trigger button
- `TableFacetedFilter` - Core faceted filter
- `TableSliderFilter` - Core slider filter
- `TableDateFilter` - Core date filter
- `TableSortMenu` - Core sort menu
- `TableViewMenu` - Core view menu
- `TableInlineFilter` - Core inline filter
- `TableClearFilter` - Core clear filter
- `TableExportButton` - Core export button
- `TableRangeFilter` - Core range filter
- `TableRowDndProvider` - Core row DnD provider
- `TableDraggableRow` - Core draggable row
- `TableRowDragHandle` - Core row drag handle
- `TableColumnDndProvider` - Core column DnD provider
- `TableDraggableHeader` - Core draggable header
- `TableDragAlongCell` - Core drag-along cell

### [Hooks](/niko-table/overview/hooks/)

React hooks for your table.

**Hooks:**

- `useDataTable` - Access table instance and context
- `useDebounce` - Debounce values for search/filters
- `useDerivedColumnTitle` - Derive column titles
- `useGeneratedOptions` - Generate filter options from data
- `useGeneratedOptionsForColumn` - Generate options for a single column
- `useKeyboardShortcut` - Manage keyboard shortcuts
- `useKeyboardShortcuts` - Batch keyboard shortcuts

## Credits and Inspirations

Niko Table builds on open-source projects and ideas from other developers.

### Core Dependencies

- **[TanStack Table](https://tanstack.com/table)** by Tanner Linsley - The headless table library under everything. It handles sorting, filtering, pagination, and more.

- **[Shadcn UI](https://ui.shadcn.com)** by Shadcn - Accessible component primitives built on Radix UI. All Niko Table UI uses them.

### Major Inspirations

- **[sadmann7's work](https://github.com/sadmann7)** - Main inspiration for the filter components and table patterns:
  - **[TableCN](https://github.com/sadmann7/tablecn)** - Inspired the filter menu, inline filter, faceted filter, and slider filter. The composition pattern and filter design come from here.
  - **[DiceUI Sortable](https://www.diceui.com/docs/components/sortable)** - Drag-and-drop sorting. Inspired the sort menu.

- **[nuqs](https://nuqs.dev/)** by François Best - Type-safe URL state. Used in the server-side examples to keep table state in the URL.

- **[Web Dev Simplified Registry](https://github.com/WebDevSimplified/wds-shadcn-registry)** by Kyle Cook - Its registry pattern shaped how this project is organized.

### Philosophy

Following the Shadcn philosophy: **"Nobody's table, everyone's solution."**

- Copy and paste the code into your project
- Own the code: change it as needed
- No extra packages (only TanStack Table and Shadcn UI)
- Fully customizable and themeable
- Written in TypeScript
