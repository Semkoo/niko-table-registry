import { Steps } from "@astrojs/starlight/components"

<Steps>

1. **Check Existing Components**

   Look at the [components list](/getting-started/components/) and the [GitHub discussions tab](https://github.com/Semkoo/niko-table-registry/discussions/categories/component-request). The component may already exist or be requested.

2. **Open a Discussion**

   Go to the GitHub repository and [start a new discussion](https://github.com/Semkoo/niko-table-registry/discussions/new?category=component-request).

3. **Describe the Component**

   Give a clear description, use cases and any references or examples. More detail makes it easier for maintainers to build it.

</Steps>
