import { Steps } from "@astrojs/starlight/components"

<Steps>

1. **Search Existing Issues**

   Look at the [GitHub issues](https://github.com/Semkoo/niko-table-registry/issues?q=is%3Aissue%20state%3Aopen%20label%3Aenhancement). Someone may have already asked for it.

2. **Open a Issue**

   Go to the GitHub repository and [open a new issue](https://github.com/Semkoo/niko-table-registry/issues) using the `Feature Request` template.

3. **Describe the Feature**

   Explain why you need it, how it should work and any alternatives. More detail makes it easier for maintainers to build it.

</Steps>

_This is not for new components. For those, see [Component Request](/contributing/component-request/)._
